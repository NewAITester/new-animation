## بررسی‌های محلی این تحویل

- ساختار XML، TOML و YAML با parser بررسی می‌شود.
- مسیر ماژول‌های ثبت‌شده و وجود فایل‌های ساخت بررسی می‌شود.
- این بررسی‌ها جایگزین کامپایل Kotlin یا اجرای Gradle نیستند.
- محیط دارای Java 25 است، اما Gradle، JDK 17 و Android SDK آماده نیستند.
- اینترنت برای نصب ابزارها فعال نشده است.
- هیچ نتیجهٔ موفق ساخت، تست، پوشش یا عملکرد ادعا نمی‌شود.
